# ritual's rab (studylocal)

내 PC에서 도는 AI 비서 **실장님** — 자비스처럼 말로 시키면 도구를 골라 직접 실행하고, 대표님에 대해 기억한 것과 앞선 대화를 늘 이어서 안다.
파일 찾아 가져오기, 폰으로 메시지 보내기, 일정·할 일·공부모드, 결재, 그리고 직원 16개 팀(4인 1조)에게 노트 PDF·문제·암기카드·마인드맵·분석·번역,
**그림(Krea-2 Turbo)·짧은 영상(Wan2.2 5B)** 을 맡긴다.
결과물은 **대표(나)의 결재**가 있어야 완료된다. PC와 폰 둘 다 시스템 알림이 오고, 폰에서도 시키고 결과를 받는다.

AI는 전부 내 PC에서 돈다 (글: Ollama, 그림·영상: ComfyUI). 파일을 인터넷 AI 서비스에 올리지 않는다.
인터넷을 쓰는 건 이것뿐: 위키문헌·위키백과 자료, 폰 알림(ntfy, 켰을 때만), 폰 원격 '어디서나'(Cloudflare 임시 터널, 켰을 때만), [배포]를 눌렀을 때 Vercel.

## 설치

필요한 것: [uv](https://docs.astral.sh/uv/), [Ollama](https://ollama.com/), [Node.js](https://nodejs.org/)(npm), Microsoft Edge 또는 Chrome.

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
vercel login   # 배포 기능을 쓸 때만, 한 번
```

`install.ps1`이 하는 일: `qwen3.5:4b` 모델 받기(없을 때만) → 파이썬 환경(`%LOCALAPPDATA%\ritual-office\venv`) → 픽셀 로고·아이콘 → Vercel CLI(없을 때만)
→ 바탕화면 **ritual's rab** 아이콘 → 윈도우 켤 때 창 없이 켜지는 자동 시작(알림·폰 연결용, 설정 탭에서 끌 수 있음).

그림·영상 AI는 따로 (약 37GB, 한 번만, 끊겨도 다시 돌리면 이어 받음):

```powershell
powershell -ExecutionPolicy Bypass -File install_gen.ps1
```

`%LOCALAPPDATA%\ritual-office\gen\`에 ComfyUI 포터블(RTX 50 지원 PyTorch 포함) + Krea-2 Turbo(그림) + Wan2.2 TI2V 5B(영상)를 받는다.

## 쓰는 법

바탕화면 아이콘을 누르면 창이 뜬다. 아래 지시 칸에 실장님께 말로 시키고 Enter (줄바꿈은 Shift+Enter). 파일은 [첨부]나 끌어다 놓기.

- `바탕화면에서 수학 프린트 찾아서 문제 10개 만들어줘` · `다운로드에 뭐 있어?` · `문서에 '준비물' 메모 만들어줘`
- `내 폰으로 굿나잇이라고 보내` · `30분 뒤에 물 마시라고 알려줘` · `오늘 뭐 해야 돼?` · `결재할 거 있어?` · `방금 거 승인해`
- `이 프린트 PDF로`(첨부) · `광합성 조사해서 암기카드랑 마인드맵` · `운수 좋은 날 가져와서 문제 5개` · `방금 자료로 암기카드`
- `@번역가 이거 일본어로`(그 팀에만 맡기기) · `꼼꼼 모드로 바꿔` · `공부모드 꺼줘` · `메모장 열어줘`
- `바다 노을 그림 2장 그려줘` · `세로로 공부하는 고양이 그려줘` · `파도치는 바다 3초 영상 만들어줘`
- `인터넷에서 ○○ 찾아서 요약해줘` · `지금 화면에 뭐 떠 있어?` · `이거 클립보드에 복사해` · `볼륨 3칸 줄여` · `배터리 얼마 남았어?` · `나 고2야, 기억해`

### 실장님이 쓰는 도구와 권한

파일 찾기 · 폴더 보기 · 파일 읽기 · 사무실로 가져오기(보관함·폰에서 받기) · 열기(파일·폴더·웹 주소·메모장 같은 앱) · 새 파일 쓰기 · 복사 · 새 폴더,
직원 팀에 일 시키기, PC·폰 알림, 나중에 알림, 일정·할 일·시험, 오늘·작업 현황, 결재·중단·처음부터 다시, 할 일 체크, 공부모드, 설정 바꾸기, 위키 조사,
**그림 그리기(Krea-2)·영상 만들기(Wan2.2), 웹 검색(Bing)·웹 페이지 읽기, 지금 화면 보고 답하기, 클립보드 복사·읽기, PC 상태(시간·배터리·디스크), 볼륨·음악 재생 키, 유튜브·네이버·구글 같은 사이트 열기, 기억하기·잊기.**
웹페이지·파일 안에 적힌 지시는 대표님 지시가 아니라서 따르지 않는다. 같은 도구를 같은 값으로 되풀이하면 다시 하지 않고 알려 준다.
실장님은 한 번 지시에 도구를 최대 8번 이어 쓰고, 카드의 **실장님 작업 기록**에 무엇을 했는지 남긴다.

- **권한**(설정 → 실장님 권한): 기본 허용 폴더 = 바탕화면·문서·다운로드·사진·음악·동영상·OneDrive(사무실 결과물도). 폴더를 빼거나 더할 수 있고, 읽기·만들기를 따로 끌 수 있다.
  허용 폴더 밖, AppData·.ssh·시스템 폴더는 늘 막힌다. 새 파일은 기본 `문서/ritual's rab/`에, 있는 파일은 절대 덮어쓰지 않는다.
- **실장님이 못 하는 것**: 지우기·옮기기·이름 바꾸기·덮어쓰기·명령 실행·프로그램(.exe·.bat 등) 실행. 시키면 못 한다고 말하고 그 폴더를 열어 준다(대표님이 직접).

### 기억 · 이어지는 대화

실장님은 대표님이 알려 준 것(이름·학년·학원 요일·좋아하는 방식·"앞으로 ~해줘")을 기억하고(`output/memory.json`), 지시할 때마다 그 기억과 최근 대화 6번을 함께 본다.
그래서 "아까 그거 폰으로 보내", "나 몇 학년이라 했지?"를 알아듣는다. "기억해" · "잊어"라고 말하거나 설정 → 실장님 기억에서 보고·지우고·직접 적는다.

### 4인 1조 팀

직원 16명마다 하위 직원 3명이 있다. 사무실에서 책상을 누르면 팀 팝업(팀장 + 3명, 지금 하는 일, 팀 최근 작업, [이 팀에 시키기]).
지시 앞에 `@이름`을 붙여도 그 팀에만 맡긴다.

### 그림 · 영상

화가 팀(Krea-2 Turbo, 8단계)이 그림을, 영상감독 팀(Wan2.2 TI2V 5B, 24fps)이 1~5초 영상을 만든다. 한국어로 시키면 실장님이 영어 프롬프트로 다듬어 넘긴다.
영상은 Krea-2가 첫 장면을 그리고 Wan2.2가 그 그림을 움직인다(글로만 만들 때보다 훨씬 깨끗하다). 첫 장면 그림도 작업 폴더에 남는다.
그림은 정사각형 1024×1024(세로·가로도 됨) 1~4장, 영상은 832×480(세로·정사각형도 됨). 결과는 카드·대표실에 바로 보이고, 결재가 있어야 완료, 반려하면 의견대로 다시 그린다.
그래픽 메모리(8GB)를 나눠 쓰려고 그리기 전에 Ollama 모델을 내리고, 다 그리면 ComfyUI 메모리를 비운다. ComfyUI는 처음 시킬 때 켜지고(1~2분) 퇴근하면 같이 꺼진다.
설정 → 이미지·동영상 AI에서 설치 상태를 보고, [ComfyUI 직접 열기]로 ComfyUI 화면도 쓸 수 있다.
실측(2026-10-22, OMEN 16 RTX 5060 8GB): 그림 1장 약 30초 · 2장 58초, 실장님에게 시키면 1장 45초 · 세로 2장 66초, 영상 2초 2분 25초, 실장님에게 3초 영상 3분 30초.
라이선스: Krea-2는 [Krea 2 Community License](https://huggingface.co/krea/Krea-2-Turbo/blob/main/LICENSE.pdf)(상업적으로 쓰기 전에 확인), Wan2.2는 Apache 2.0.

### 편의 기능

- 카드: [중단](대기는 바로, 진행 중이면 지금 단계 끝나고) · [처음부터 다시] · [고쳐서 다시](지시를 지시 칸에 다시, 그 자료를 고른 채로) · ☆ 즐겨찾기 · [제목 바꾸기] · [한 번에 받기(zip)] · 대기 순번.
- **보관함 [전체 기록]**: 지난 작업 전부를 날짜별로, 검색·상태·★ 필터, 30개씩 더 보기. 옛 작업도 결과 열기·이 자료로 더 하기·★·지우기가 된다.
- 지시 칸 위 **빠른 지시** 버튼(○○ 자리가 골라져 있어 바로 고쳐 씀), 지시 칸이 비었을 때 ↑↓로 이전 지시.
- 설정 → **초기화**: 직원 자리 정리 · 대기열 비우기 · 모두 중단 · 보관함 정리(★·결재 대기는 남김) · 완료한 할 일 지우기 · 설정 기본값 · 화면 배치·안내 초기화 (전부 두 번 눌러야 실행).

### 화면

탭: **사무실 · 보관함 · 오늘 · 일정 · 대표실 · 설정**. [나눠 보기]를 켜면 두 탭을 나란히 본다(넓은 화면, 창마다 탭을 고름, 배치는 기억).

- **사무실**: 4개 팀 책상, 말풍선으로 지금 하는 일, 대표실 문(결재 대기 수), 업무 일지.
- **보관함**: 작업 번호(No.0001…), 검색·거르기, 결과 버튼(분석·PDF·문제·암기카드·마인드맵·번역·CSV·원문), [이 자료로 더 하기], 에러 [다시], [지우기](두 번), 승인 도장.
- **오늘**: 오늘 할 일(체크·알림 시각), 밀린 일 [오늘로], 오늘 일정, 오늘 공부 시간·연속 공부·7일 막대.
- **일정**: 일정·시험·숙제(알림, 매일·매주 반복), 앞으로 30일, D-day.
- **대표실**: 결재함(미리보기 + 승인/반려와 의견), 회사 현황(오늘 처리·결재 대기·승인율·이번 주 공부), 조직도·직원별 실적, 자동 승인 규칙, 결재 이력.
- **설정**: AI 모드, PC·폰 알림, 아침 브리핑, 폰으로 일 시키기(QR), 윈도우 자동 시작, 데이터 백업(zip), 단축키.

**공부모드**: 헤더 [공부모드](Alt+G) → 할 일 고르고 25·50분 집중 / 5·10분 쉬기. 창을 닫아도 시간은 서버가 재고, 끝나면 알림이 온다.

단축키: `Alt+1~6` 탭 · `Alt+S` 나눠 보기 · `Alt+G` 공부모드 · `/` 지시 칸 · `Esc` 닫기.

### 대표 결재

결과물이 생긴 작업은 **결재 대기**가 되고, 대표실에서 [승인]해야 **완료**된다. [반려]할 땐 뭘 고칠지 적으면 직원들이 같은 자료로 다시 만들어 다시 올린다(수정본 1, 2…).
배포는 승인된 작업만. **자동 승인 규칙**으로 종류별로 실장에게 맡길 수 있다(기본: 답변만 자동 승인).

### 알림 (PC + 폰)

일정·할 일 알림, 내일 시험, 공부모드 끝, 결재 요청, 작업 완료·실패, 아침 브리핑(기본 07:30).

- **PC**: Windows 알림 센터 (앱 이름: ritual's rab).
- **폰**: 설정 → 폰 알림 켜기 → 폰에 [ntfy](https://ntfy.sh) 앱 설치 → 화면에 나온 주제 이름 구독 → [테스트 알림]. 주제 이름이 비밀번호 역할이다.

PC가 꺼져 있으면 알림도 없다. 그래서 윈도우 켤 때 사무실이 창 없이 켜진다.

### 폰으로 일 시키기

설정 → **폰으로 일 시키기**: 끔(기본) / 같은 와이파이 / 어디서나. 켜면 QR이 나온다 → 폰 카메라로 찍으면 폰 화면(`/m`)이 열린다.
폰에서: 사진 찍어 올리기 · 지시 · 진행 상황 · 결과 내려받기 · 결재 · 오늘 할 일 체크.

- 모든 요청에 열쇠(토큰)가 필요하다. 링크를 한 번 열면 폰이 90일 기억한다. 링크를 잃어버리면 [열쇠 바꾸기].
- **같은 와이파이**: 처음 켤 때 Windows 방화벽 창이 뜨면 '허용'.
- **어디서나**: Cloudflare 임시 터널(계정 없음, 처음 켤 때 `cloudflared`를 내려받음). 켤 때마다 주소가 바뀌어서 새 주소를 폰 알림으로 보낸다.
- 폰에선 PC 전용 기능(종료·백업·설정·폴더 열기)은 안 된다.

## AI 모드와 속도

|---|---|---|
| 프린트 사진 글자 읽기 (OCR) | 15초 | 5초 |
| 노트 PDF | 25초 | 11~13초 |

빠름 모드 2단계 실측: 질문 답변 11초 · 조사+암기카드+마인드맵 24초 · 사진 분석 15초 · 워드 번역 3초 · 일정 등록 5초 · 시험 일정+공부 계획 10초 · 공부모드 2초 · 작품+문제 5개 25초 · 반려 후 다시 만들기 15초.
꼼꼼 모드는 9.7B를 GPU에 다 올려 55 tok/s(노트 16초). 다른 프로그램이 그래픽 메모리를 많이 쓰면 자동으로 Ollama 기본 배치로 돌아간다.
모델 이름을 바꾸려면 환경 변수 `RITUAL_FAST_MODEL`(빠름) / `RITUAL_MODEL`(꼼꼼)을 `setx`로 정하고 사무실을 다시 켠다.

## 결과물 위치

`output/jobs/<작업 폴더>/`: 원본(`inputs/`), 읽은 글(`source.txt`, `material.json`), 노트(`note.pdf`), 문제(`quiz/`), 암기카드(`cards/`, `cards.csv`), 마인드맵(`mindmap/`), 분석(`analysis/`), 번역(`translation/`), 답변(`answer.md`), 그림(`images/`), 영상(`video/`), 작업 기록(`job.json`).
일정·할 일은 `output/planner.json`, 설정은 `output/settings.json`·`auto_approve.json`·`remote.json`. 설정 → [백업 받기]로 전부 zip 하나로 받는다(되돌리려면 `output`에 풀기).
배포용 사이트는 `output/ritual-quiz/`. 배포한 문제를 내리려면 `output/ritual-quiz/q/<작업 폴더>`를 지우고 아무 문제나 다시 [배포].

## 문제 해결

- **상태등이 "Ollama 꺼짐"**: 작업 표시줄에서 Ollama를 켜거나 `ollama serve`. 사무실 아이콘을 누를 때도 자동으로 켜 본다.
- **"모델 qwen3.5:4b이(가) 없어"**: 터미널에서 `ollama pull qwen3.5:4b` (꼼꼼 모드는 `ollama pull qwen3.5`).
- **느릴 때**: 전원을 연결하고 GPU를 쓰는 앱(게임·영상 편집)을 끈다. 빠름 모드인지 헤더에서 확인.
- **폰 알림이 안 올 때**: 설정 → [테스트 알림], ntfy 앱의 구독 주제가 화면과 같은지 확인.
- **폰 화면이 "잠겨 있어"**: PC 설정 탭의 QR로 다시 들어간다(열쇠를 바꿨으면 옛 링크는 안 열림).
- **"사무실 서버가 꺼졌어"**: 바탕화면 아이콘을 다시 누른다.
- **배포가 안 될 때**: 터미널에서 `vercel login`.
- **그림·영상이 안 될 때**: 설정 → 이미지·동영상 AI에 빠진 게 있으면 `install_gen.ps1`을 다시 돌린다(받은 건 건너뜀). ComfyUI 로그는 `%LOCALAPPDATA%\ritual-office\comfy.log`.
- **로그**: `%LOCALAPPDATA%\ritual-office\office.log`
