# ritual의 공부 사무실 (studylocal)

내 PC의 로컬 AI(qwen3.5) 직원 14명이 학교 프린트·문서를 노트 PDF, 문제 풀이 웹, 암기카드, 마인드맵, 분석 보고서, 번역으로 바꿔 주는 픽셀 아트 사무실.
일정·오늘 할 일·공부모드도 챙기고, 결과물은 **대표(나)의 결재**가 있어야 완료된다. PC와 폰 둘 다 시스템 알림이 오고, 폰에서도 일을 시키고 결과를 받을 수 있다.

AI는 전부 내 PC의 Ollama에서 돈다. 프린트를 인터넷 AI 서비스에 올리지 않는다.
인터넷을 쓰는 건 이것뿐: 위키문헌·위키백과 자료 가져오기, 폰 알림(ntfy, 켰을 때만), 폰 원격 '어디서나'(Cloudflare 임시 터널, 켰을 때만), [배포]를 눌렀을 때 Vercel.

## 설치

필요한 것: [uv](https://docs.astral.sh/uv/), [Ollama](https://ollama.com/), [Node.js](https://nodejs.org/)(npm), Microsoft Edge 또는 Chrome.

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
vercel login   # 배포 기능을 쓸 때만, 한 번
```

`install.ps1`이 하는 일: `qwen3.5:4b` 모델 받기(없을 때만) → 파이썬 환경(`%LOCALAPPDATA%\ritual-office\venv`) → 픽셀 로고·아이콘 → Vercel CLI(없을 때만)
→ 바탕화면 **ritual의 공부 사무실** 아이콘 → 윈도우 켤 때 창 없이 켜지는 자동 시작(알림·폰 연결용, 설정 탭에서 끌 수 있음).

## 쓰는 법

바탕화면 아이콘을 누르면 사무실 창이 뜬다. 처음엔 안내가 한 번 나온다. 아래 **지시 칸**에 말로 시키고 Enter (줄바꿈은 Shift+Enter).
파일은 [첨부]를 누르거나 창 어디에든 끌어다 놓는다.

- `이 프린트 예쁘게 PDF로 만들어줘` · `이 한글 파일 분석해줘` · `이 문서 영어로 번역해줘` (첨부)
- `광합성 조사해서 암기카드랑 마인드맵 만들어줘` · `광합성이 뭐야?`
- `운수 좋은 날 가져와서 문제 10개 만들어줘` · `방금 자료로 암기카드 만들어줘`
- `내일 3시 수학 학원 일정 넣어줘` · `기말고사 11월 20일인데 공부 계획 짜줘` · `25분 공부모드 켜줘`

파일만 올리고 아무 말 안 하면 분석가가 분석 보고서를 쓴다.

**읽을 수 있는 파일**: 사진(JPG·PNG·WEBP·BMP·GIF·TIFF), PDF(최대 20쪽), 한글(HWP·HWPX), 워드(DOCX), 파워포인트(PPTX), 엑셀(XLSX), 글자 파일(TXT·MD·CSV·HTML·JSON·코드 등).
문서는 AI 없이 글자를 바로 꺼낸다(표는 `칸 | 칸`). 암호·배포용 한글 파일, 옛 형식(.doc·.ppt·.xls), 소리·영상, 아이폰 HEIC는 이유와 바꾸는 법을 알려준다.

### 화면

탭: **사무실 · 보관함 · 오늘 · 일정 · 대표실 · 설정**. [나눠 보기]를 켜면 두 탭을 나란히 본다(넓은 화면, 창마다 탭을 고름, 배치는 기억).

- **사무실**: 4개 팀 책상, 말풍선으로 지금 하는 일, 대표실 문(결재 대기 수), 업무 일지.
- **보관함**: 작업 번호(No.0001…), 검색·거르기, 결과 버튼(분석·PDF·문제·암기카드·마인드맵·번역·CSV·원문), [이 자료로 더 하기], 에러 [다시], [지우기](두 번), 승인 도장.
- **오늘**: 오늘 할 일(체크·알림 시각), 밀린 일 [오늘로], 오늘 일정, 오늘 공부 시간·연속 공부·7일 막대.
- **일정**: 일정·시험·숙제(알림, 매일·매주 반복), 앞으로 30일, D-day.
- **대표실**: 결재함(미리보기 + 승인/반려와 의견), 회사 현황(오늘 처리·결재 대기·승인율·이번 주 공부), 조직도·직원별 실적, 자동 승인 규칙, 결재 이력.
- **설정**: AI 모드, PC·폰 알림, 아침 브리핑, 폰으로 일 시키기(QR), 윈도우 자동 시작, 데이터 백업(zip), 단축키.

**공부모드**: 헤더 [공부모드](Alt+G) → 할 일 고르고 25·50분 집중 / 5·10분 쉬기. 창을 닫아도 시간은 서버가 재고, 끝나면 알림이 온다.

단축키: `Alt+1~6` 탭 · `Alt+S` 나눠 보기 · `Alt+G` 공부모드 · `/` 지시 칸 · `Esc` 닫기.

### 대표 결재

결과물이 생긴 작업은 **결재 대기**가 되고, 대표실에서 [승인]해야 **완료**된다. [반려]할 땐 뭘 고칠지 적으면 직원들이 같은 자료로 다시 만들어 다시 올린다(수정본 1, 2…).
배포는 승인된 작업만. **자동 승인 규칙**으로 종류별로 실장에게 맡길 수 있다(기본: 답변만 자동 승인).

### 알림 (PC + 폰)

일정·할 일 알림, 내일 시험, 공부모드 끝, 결재 요청, 작업 완료·실패, 아침 브리핑(기본 07:30).

- **PC**: Windows 알림 센터 (앱 이름: ritual의 공부 사무실).
- **폰**: 설정 → 폰 알림 켜기 → 폰에 [ntfy](https://ntfy.sh) 앱 설치 → 화면에 나온 주제 이름 구독 → [테스트 알림]. 주제 이름이 비밀번호 역할이다.

PC가 꺼져 있으면 알림도 없다. 그래서 윈도우 켤 때 사무실이 창 없이 켜진다.

### 폰으로 일 시키기

설정 → **폰으로 일 시키기**: 끔(기본) / 같은 와이파이 / 어디서나. 켜면 QR이 나온다 → 폰 카메라로 찍으면 폰 화면(`/m`)이 열린다.
폰에서: 사진 찍어 올리기 · 지시 · 진행 상황 · 결과 내려받기 · 결재 · 오늘 할 일 체크.

- 모든 요청에 열쇠(토큰)가 필요하다. 링크를 한 번 열면 폰이 90일 기억한다. 링크를 잃어버리면 [열쇠 바꾸기].
- **같은 와이파이**: 처음 켤 때 Windows 방화벽 창이 뜨면 '허용'.
- **어디서나**: Cloudflare 임시 터널(계정 없음, 처음 켤 때 `cloudflared`를 내려받음). 켤 때마다 주소가 바뀌어서 새 주소를 폰 알림으로 보낸다.
- 폰에선 PC 전용 기능(종료·백업·설정·폴더 열기)은 안 된다.

| 팀 | 직원 | 하는 일 |
|---|---|---|
| 경영지원팀 | 실장 | 명령을 읽고 누가 무슨 일을 할지 정한다. 애매하면 되묻는다. 결재를 올린다 |
| | 비서 | 말로 한 일정·할 일을 정리해 등록하고 알림을 맡는다 (사진 속 가정통신문도 읽음) |
| | 배포담당 | 승인된 문제 페이지를 Vercel에 올려 공개 링크를 만든다 |
| 자료조사팀 | 스캐너 | 사진·PDF·한글·워드·PPT·엑셀·글자 파일을 읽는다 |
| | 사서 | 문학 작품: 저작권이 끝난 작품만 위키문헌 원문, 나머지는 해설 |
| | 조사원 | 개념·인물·사건 같은 주제를 위키백과에서 조사한다 |
| | 분석가 | 자료 종류·과목·난이도, 핵심, 시험 포인트, 헷갈리는 것, 공부법·예상 시간 보고서 |
| 콘텐츠제작팀 | 디자이너 | 노트 PDF (픽셀 로고, 핵심·용어·요약) |
| | 출제위원 | 객관식·OX·단답 문제와 해설, 한 장짜리 문제 풀이 웹 |
| | 암기담당 | 암기카드 웹(뒤집기·알아/몰라) + Anki용 CSV |
| | 정리왕 | 한 장짜리 개념 마인드맵 (인쇄 가능) |

| | 코치 | 시험 대비 날짜별 공부 계획, 공부모드 |

## AI 모드와 속도

설정 → AI 모드: **빠름**(기본, `qwen3.5:4b` 4.2B) / **꼼꼼**(`qwen3.5:latest` 9.7B, 모델 전체를 GPU에 올림).

2026-10-21, OMEN 16 (RTX 5060 Laptop 8GB, RAM 32GB), 전원 연결, `NUM_CTX 16384`. 시험 프린트: A4 한 장 "세포의 구조"(`tests/fixtures/handout.html`).

| 작업 | 1단계 (9.7B) | 지금 빠름 (4B) |
|---|---|---|
| 프린트 사진 글자 읽기 (OCR) | 15초 | 5초 |
| 노트 PDF | 25초 | 11~13초 |
| 문제 5개 | 16초 | 10~18초 |
| 작품 가져오기 (운수 좋은 날) | 18초 | 9초 |
| 글 생성 속도 | 37 tok/s (16%가 CPU) | 84 tok/s (100% GPU) |

빠름 모드 2단계 실측: 질문 답변 11초 · 조사+암기카드+마인드맵 24초 · 사진 분석 15초 · 워드 번역 3초 · 일정 등록 5초 · 시험 일정+공부 계획 10초 · 공부모드 2초 · 작품+문제 5개 25초 · 반려 후 다시 만들기 15초.
꼼꼼 모드는 9.7B를 GPU에 다 올려 55 tok/s(노트 16초). 다른 프로그램이 그래픽 메모리를 많이 쓰면 자동으로 Ollama 기본 배치로 돌아간다.
모델 이름을 바꾸려면 환경 변수 `RITUAL_FAST_MODEL`(빠름) / `RITUAL_MODEL`(꼼꼼)을 `setx`로 정하고 사무실을 다시 켠다.

## 결과물 위치

`output/jobs/<작업 폴더>/`: 원본(`inputs/`), 읽은 글(`source.txt`, `material.json`), 노트(`note.pdf`), 문제(`quiz/`), 암기카드(`cards/`, `cards.csv`), 마인드맵(`mindmap/`), 분석(`analysis/`), 번역(`translation/`), 답변(`answer.md`), 작업 기록(`job.json`).
일정·할 일은 `output/planner.json`, 설정은 `output/settings.json`·`auto_approve.json`·`remote.json`. 설정 → [백업 받기]로 전부 zip 하나로 받는다(되돌리려면 `output`에 풀기).
배포용 사이트는 `output/ritual-quiz/`. 배포한 문제를 내리려면 `output/ritual-quiz/q/<작업 폴더>`를 지우고 아무 문제나 다시 [배포].

## 확인 (테스트)

```powershell
uv run pytest -q                                              # 단위·API 테스트 (AI 없이, 4초)
$env:RITUAL_E2E="1"; uv run pytest tests/test_ui.py -q        # 화면 E2E: 설치된 Edge로 클릭·입력·끌어놓기·다운로드·폰 화면
$env:RITUAL_LIVE="1"; uv run pytest tests/test_live.py -q -s  # 실제 qwen3.5 + 위키로 직원 전부 실측 (약 3분)
```

## 문제 해결

- **상태등이 "Ollama 꺼짐"**: 작업 표시줄에서 Ollama를 켜거나 `ollama serve`. 사무실 아이콘을 누를 때도 자동으로 켜 본다.
- **"모델 qwen3.5:4b이(가) 없어"**: 터미널에서 `ollama pull qwen3.5:4b` (꼼꼼 모드는 `ollama pull qwen3.5`).
- **느릴 때**: 전원을 연결하고 GPU를 쓰는 앱(게임·영상 편집)을 끈다. 빠름 모드인지 헤더에서 확인.
- **폰 알림이 안 올 때**: 설정 → [테스트 알림], ntfy 앱의 구독 주제가 화면과 같은지 확인.
- **폰 화면이 "잠겨 있어"**: PC 설정 탭의 QR로 다시 들어간다(열쇠를 바꿨으면 옛 링크는 안 열림).
- **"사무실 서버가 꺼졌어"**: 바탕화면 아이콘을 다시 누른다.
- **배포가 안 될 때**: 터미널에서 `vercel login`.
- **로그**: `%LOCALAPPDATA%\ritual-office\office.log`
